Which Windows 10 and Windows 11 driver does your Magic Mouse need?

Turn the mouse over and look at the connector. A door for AA batteries or a thin Lightning port means Magic Mouse v1 or v2, and you install Apple's Boot Camp Windows driver. A small oval USB-C port means Magic Mouse v3, Apple's 2024 model, and it needs a different Windows driver called KMDF.

  • A Windows driver is the small program Windows uses to talk to a piece of hardware. Everything on this page is for Windows 10 and Windows 11.
  • Windows doesn't treat every Apple mouse the same, so there is no single download.
  • “v3” is our shorthand, not Apple's name. Apple calls it Magic Mouse (2024) with USB-C. We say v3 because that's what people type when they search.
  • Install the one that matches your mouse. Magic Tray won't guess for you.

Three separate things, so nobody mixes them up. One, battery percent in the tray works for mice, keyboards and trackpads. Two, the scrolling Windows driver is for the Magic Mouse only. Three, among mice, v1 and v2 use Apple's Boot Camp driver, while the v3 needs KMDF because Boot Camp has no entry for PID 0323.

Not sure which mouse you have? A Magic Mouse v2 and a v3 look identical from above. Ask Windows first, then check the connector. Putting the v3 driver on an older mouse, or Apple's driver on a v3, leaves you with a mouse that scrolls worse than before.

How do you check which Magic device you have in Windows Device Manager?

Open Device Manager, find your Apple device, and read its Hardware Ids. The four characters after PID_ are the code Windows uses to tell one model from another. 0323 is the Magic Mouse v3, Apple's 2024 model. Then turn the device over and check the connector to confirm.

  • PID is short for product id. It's the four-character code Windows uses to tell one model from another, and it's the only answer you can fully trust.
  • The connector on the bottom is strong evidence too, but a Magic Mouse v2 and v3 look the same from above.

1. Ask Windows which mouse it thinks you have

  1. Right-click the Start button. Click Device Manager.
  2. Open Mice and other pointing devices (or Keyboards).
  3. Double-click the Apple device.
  4. Open the Details tab. Pick Hardware Ids in the list.
  5. Read the four characters after PID_ or PID&. That's your PID.

If your PID isn't listed on this page, don't guess and don't install anything. Tell us the PID and we'll add it.

2. Now turn the device over and look at the connector

  • AA batteries and no port at all — a wide door on the bottom of a Magic Mouse v1 or an Apple Wireless Mouse, or a round screw cap on the end of an older keyboard or trackpad.
  • Thin Lightning port (the shape an older iPhone charger plugs into) — Magic Mouse v2, Magic Trackpad 2, or the Lightning Magic Keyboard.
  • Small oval USB-C port (the shape most new phones use) — Magic Mouse v3, or the 2024 trackpad or keyboard.

Magic Mouse v3 (2024, USB-C, PID 0323): which Windows driver fixes scrolling?

The Magic Mouse v3 needs the KMDF Windows driver. KMDF is just the kind of driver Windows loads deep in the system, next to its own. This one is a filter driver: it sits between Windows and the mouse and turns Apple's finger data into scrolling. Left alone, Windows 10 and 11 give you a moving cursor and no scroll.

  • This is the mouse with the USB-C port on the bottom. Windows shows PID 0323.
  • Apple calls it Magic Mouse (2024). “v3” is our shorthand, and it's what people search for.
  • The driver comes from a separate project of ours, not from Magic Tray itself.
  • Pictures and the longer story: why the Magic Mouse v3 is the hard one on Windows.

Why does the Magic Mouse v3 (2024, USB-C) need a different Windows driver?

Apple stopped updating Boot Camp before the 2024 model shipped, so no Apple driver for Windows lists PID 0323. Windows falls back to its own basic mouse support. Your cursor still moves, but finger scrolling usually stops, because nothing is translating the mouse's touch data.

Boot Camp was Apple's package of Windows drivers for Mac hardware. It's where the working Windows driver for the Magic Mouse v1 and v2 came from, and Apple stopped updating it years ago.

Where does the Magic Mouse v3 driver sit in Windows, and what does it do?

Windows talks to your mouse through a stack of layers, one on top of the other. The driver slides into the middle of that stack as a LowerFilter, which is Windows' name for a driver that sits below the standard one and sees the raw data first. It turns finger movement into scrolling and passes everything else along.

You'll see HID in the diagram below. HID is the standard language Windows uses for mice and keyboards. Apple's mice speak it for cursor movement, but they send touch data in their own format, which is why Windows needs a translator in the middle. The same diagram, with more detail, is on the Magic Mouse v3 page.

How do you install the Windows driver for the Magic Mouse v3?

  1. Read the safety section first. This changes two Windows settings.
  2. Turn on Test Mode: run bcdedit /set testsigning on in an admin Command Prompt, turn Memory integrity off in Windows Security, then restart the PC.
  3. Run Install-KMDF.cmd, or let Magic Tray prompt you. Magic Tray won't quietly fall back to a patched Apple driver.
  4. If scrolling still doesn't work, unpair the mouse in Bluetooth settings and pair it again.

This is for the Magic Mouse v3 only. Full walkthrough: how to install the Magic Mouse v3 Windows driver. Still stuck afterwards: the scroll fix page.

Magic Mouse v1 (AA batteries) and v2 (Lightning): which Windows driver do you install?

Install Apple's own Boot Camp Windows driver on a Magic Mouse v1 or v2. Apple wrote it for these mice years ago and it still works on Windows 10 and 11. Scrolling comes back, you don't turn on Test Mode, and you change no Windows security setting. Don't put the Magic Mouse v3 driver on these mice.

  • The Magic Mouse v1 has a door for two AA batteries. The v2 is rechargeable, with a Lightning port on the bottom.
  • We point you at the copy packaged by tealtadpole, so you don't have to dig through an old Boot Camp download.
  • It arrives as an INF package. An INF file is a plain text list that tells Windows which files to copy and which device they belong to.
  • Apple's driver is already signed, so Windows loads it normally. No Test Mode, no watermark.

Do you need a Windows driver for a Magic Keyboard on Windows 10 or 11?

No. Your Magic Keyboard already types on Windows 10 and 11, and Magic Tray doesn't change that. The scrolling driver on this page is for the Magic Mouse only. The one thing missing on a keyboard is the battery percent, and one small script from the release fixes it.

  • The script is Install-KeyboardBattery.cmd, in the latest release.
  • It edits the keyboard's SDP entry. SDP is the short list a Bluetooth device publishes to say what it can do, and Apple's keyboards leave the battery off that list on Windows.
  • If you unpair the keyboard, run the script again. Pairing again wipes the change.

Do you need a Windows driver for a Magic Trackpad on Windows 10 or 11?

No. Your Magic Trackpad already moves the cursor and clicks on Windows 10 and 11. Magic Tray only adds the battery percent to the tray. The scrolling driver on this page is for the Magic Mouse only. Magic Tray does not add trackpad gestures such as tap-to-click, pinch to zoom or three-finger swipe.

  • Gestures are a different job from the one this project does. Don't buy a Magic Trackpad expecting Magic Tray to add them.
  • A door for AA batteries (PID 030E), a Lightning port (0265) or a USB-C port (0324) tells you which generation you have.

Is it safe to install these Windows drivers?

Apple's Boot Camp driver for Magic Mouse v1 and v2 is safe in the ordinary sense. It's Apple's own signed driver, and Windows loads it with nothing switched off. The KMDF driver for the Magic Mouse v3 is a real tradeoff: Microsoft hasn't signed it, so you turn on Test Mode and turn Memory integrity off.

What is Test Mode in Windows 10 and Windows 11, and what does it cost you?

Test Mode is a Windows setting that lets your PC load drivers Microsoft has not signed. Signing is a stamp that proves who made a driver and that nobody changed it since. With Test Mode on, that check is off for every driver, not only ours, and Windows puts a watermark on your desktop.

  • What you give up. Windows normally refuses unsigned drivers. In Test Mode it accepts them, so a bad driver from anywhere else could load too.
  • Memory integrity off. That's a separate Windows protection, and unsigned drivers can't load while it's on. Turning it off removes one real layer of defence.
  • You'll see it. A watermark appears in the bottom corner of your desktop, and some games with anti-cheat refuse to start in Test Mode.
  • It's reversible. Run bcdedit /set testsigning off, turn Memory integrity back on, restart, and Windows is back to normal. Scrolling on the Magic Mouse v3 goes back to broken.
  • Only you can judge it. On a shared or work PC, or one you bank on, that may be a bad deal. On your own machine it's a choice you can make with your eyes open.
  • None of this applies to the v1 or v2. Apple's driver is signed, so those mice need no Test Mode at all.

Getting the Magic Mouse v3 driver signed by Microsoft would remove all of this, and it costs money we don't have yet. How signing works and where we stand.

What can go wrong when you install a Windows driver?

A driver runs deep inside Windows, so a bad one can crash your PC or stop a device working. The realistic risks here are smaller. Usually the mouse ends up on the wrong driver and scrolls worse than before, or Windows quietly puts its own driver back after an update.

  • Wrong driver on the wrong mouse. The most common mistake. Check your PID in Device Manager before you install anything.
  • A Windows update swaps it back. Windows sometimes replaces a driver it doesn't recognise. Reinstall and restart.
  • How to undo it. In Device Manager, open the device, then Driver, then Roll Back Driver or Uninstall device. Windows puts its own driver back on the next restart.

What if your Magic Mouse still will not scroll after you install the driver?

Check three things, in this order. First, that Device Manager shows the new driver on the mouse and not Microsoft's own. Second, that Test Mode is really on, which needs a restart after you switch it. Third, unpair the mouse in Bluetooth settings and pair it again, so Windows reloads the driver.

Five checks, in order, when scrolling is still dead

  1. Confirm which driver is loaded. Device Manager → your mouse → Driver tab. If the provider says Microsoft, the install didn't take.
  2. Confirm Test Mode (Magic Mouse v3 only). The watermark in the desktop corner is the giveaway. No watermark after a restart means it isn't on.
  3. Confirm Memory integrity is off (Magic Mouse v3 only). Windows Security → Device security → Core isolation. Unsigned drivers won't load while it's on.
  4. Unpair and pair again. Settings → Bluetooth & devices → remove the mouse, then add it back.
  5. Check the PID once more. If Windows shows 030D or 0269, you have a v1 or v2 and you want Apple's Boot Camp driver, not the KMDF one.

Still nothing? Open an issue with your Windows version and the PID from Device Manager: Magic Tray issues. For problems with the Magic Mouse v3 driver itself, the scroll fix page goes deeper.
