Which mouse do I have?

Why it moves but won't scroll

Windows drives a Magic Mouse as a plain two-button mouse and never reads the touch surface on top. A driver is the software that turns finger movement into scrolling.

AA, Lightning and Apple Wireless: Apple's own driver

The v1 (030D), v2 (0269) and Apple Wireless Mouse (0310) take a driver Apple wrote years ago. It still works on Windows 10 and 11.

Six steps

  1. 1
    Right-click the Magic Tray icon.

    Open your mouse, then Driver.

  2. 2
    Click Boot Camp.

    Magic Tray opens Apple's download page.

  3. 3
    Click the green Code button,

    then Download ZIP.

  4. 4
    Open the download.

    Drag the AppleWirelessMouse folder to your desktop.

  5. 5
    Open that folder.

    Right-click AppleWirelessMouse and choose Install. Click Yes when Windows asks.

  6. 6
    Restart your PC,

    then scroll with one finger.

Without Magic Tray, the same files are on tealtadpole's page.

Show the technical details

Boot Camp is Apple's name for its own Windows drivers, not a Mac.

The package is Apple's applewirelessmouse.sys, signed by Apple's own catalogue, so nothing gets switched off. Step 5 targets AppleWirelessMouse.inf. The tray only opens the download page: no pnputil, no rebind. Stock Windows undoes it.

The Magic Mouse 2024 with USB-C: nothing to install yet

The 2024 USB-C mouse (0323) has no finished scroll fix you can install today. Its battery percent already works with no driver, confirmed by a tester.

Why this one is hard

2024 Magic Mouse underside: Apple product image, © Apple Inc., used unmodified apart from resizing; not Creative Commons licensed.

The driver itself lives on this project's driver pages. It will appear there when it is finished.

  • Community driver: the tray's Driver menu lists it, but it isn't published. Pick it and the tray stops with an error.
  • Patched Apple driver: real today. Scrolling or battery, never both, and unconfirmed.
  • Microsoft has checked neither. Both need a Windows startup setting that lowers a real protection.
What that Windows startup setting costs you
  • Windows accepts unchecked drivers, from anywhere.
  • Memory integrity goes off, which removes a real layer of defence.
  • Grey text in your desktop corner, and some anti-cheat games won't start.
  • On a work PC, a bad deal. A driver Microsoft has checked removes all of it.

Picking the community driver before it is published never quietly switches you to the patched Apple driver instead. File paths and HID detail: the 2024 mouse page.

Questions

Why won't my Apple Magic Mouse scroll on Windows 11?

Windows never reads the touch surface on top, so one-finger scrolling does nothing until you add a driver. The three older mice take Apple's own driver. The 2024 USB-C mouse (0323) has no finished scroll fix yet.

Which driver does my Apple Magic Mouse need on Windows 10 or 11?

The Magic Mouse v1 (030D), the Magic Mouse v2 (0269) and the Apple Wireless Mouse (0310) all take Apple's own driver. The 2024 USB-C mouse (0323) has no finished scroll fix to download yet.

Can I make the 2024 USB-C Magic Mouse scroll on Windows yet?

Not yet. The community driver for that mouse isn't published, so nobody can download or install it, and its battery percent works with no driver anyway.

Will Magic Tray change my mouse driver without asking?

No. It opens a download page for the older Magic Mice, and for the 2024 mouse it asks before it installs anything.

My Magic Mouse still won't scroll. What do I check?

If the Driver tab still says Microsoft, run the install again. If nothing changed after a restart, unpair the mouse in Windows Bluetooth settings and pair it again.

Still no scrolling?

  • Driver tab still says Microsoft: the install didn't take. Run it again.
  • Nothing changed after a restart: unpair in Settings, then pair again.
  • It worked, then stopped: a Windows update swapped the driver back.
  • Windows shows 0323: no scroll driver to install yet.
  • Still nothing: open an issue with your Windows version and mouse code.

Keyboards and trackpads need no driver swap: the keyboard battery unlock, a trackpad on Windows.
