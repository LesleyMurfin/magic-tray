Which Windows driver do I need?

There is no single Apple mouse INF that is correct for every Magic device. Pick the PID you have. Magic Tray will not silently rebind.

  • Magic Mouse 2024 / v3 (USB-C)PID 0323 · KMDF · Test Mode until we get attestation
  • Magic Mouse v1, v2, or Apple Wireless MousePID 030D / 0269 / 0310 · Boot Camp · no Test Mode
  • Magic Keyboard / Apple Wireless KeyboardNo .sys · SDP patch · -Mac required
  • Magic TrackpadNo driver from us · battery only

Device Manager → Hardware Ids. USB-C mouse ≈ 0323. Lightning ≈ 0269. AA door ≈ 030D.

Magic Mouse 2024 / v3 — 0323

KMDF from magic-mouse-v3-windows-fix — only path we recommend for scroll and battery (Input 0x90 COL02). Why not v2: research. Why Test Mode: signing.

Keyboards
