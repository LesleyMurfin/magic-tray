Why does my Magic Mouse move the pointer but not scroll?

Windows drives an Apple Magic Mouse as a plain two-button mouse. It never reads the touch surface on top, so finger scrolling does nothing.

A driver teaches Windows to turn that finger movement into scrolling. Which one you need depends on your mouse.

The AA, Lightning and Apple Wireless mice: Apple's own driver

The Magic Mouse v1 (030D), v2 (0269) and the Apple Wireless Mouse (0310) all take a Windows driver Apple wrote years ago, and it still works on Windows 10 and 11.

Nothing about Windows changes, and no warning appears on your desktop.

Boot Camp is Apple's name for its own Windows drivers. You don't need a Mac, and you install nothing called Boot Camp.

Eight steps

  1. Right-click the Magic Tray icon. Open your mouse, then Driver.
  2. Click Boot Camp. Magic Tray opens the download page.
  3. On that page, click the green Code button.
  4. Click Download ZIP.
  5. Open the downloaded file. Drag the AppleWirelessMouse folder to your desktop.
  6. Open that folder. Right-click AppleWirelessMouse and choose Install.
  7. Windows asks for permission. Click Yes.
  8. Restart your PC, then scroll with one finger.

No Magic Tray open? The same files live on tealtadpole's download page.

Show the technical details

The package is Apple's Boot Camp applewirelessmouse.sys. It ships with Apple's own signature catalogue, so Windows loads it with nothing switched off.

Step 5 targets AppleWirelessMouse.inf. The tray's Boot Camp item only opens the download page: no pnputil, no rebind.

Want to go back to plain Windows? The Driver menu has Stock Windows, which undoes this.

The Magic Mouse 2024 with USB-C: no scroll fix to download yet

The 2024 USB-C Magic Mouse (0323) has no finished scroll fix you can install today. The community driver it needs is still being built, so there is nothing to download.

Your battery percent on this mouse already works with no driver at all, and a tester has confirmed it. See it in the tray.

  • Scrolling is the only thing missing. Nobody can install that driver yet, from the tray or by hand.
  • Why this mouse is the awkward one: the 2024 mouse explained.
  • What would finish it: a driver Microsoft has checked.

The tray's Driver menu already lists the community driver. Once it's published, picking it will download and install it after you confirm.

Pick it today and the tray stops with an error.

The menu's other choice, the patched Apple driver, does have an installer today. On that route you get scrolling or battery, never both, and nobody has confirmed it.

Neither driver has been checked by Microsoft, and the startup setting they need lowers a real security protection.

What that Windows startup setting costs you
  • Windows normally refuses a driver nobody has checked. Now it accepts them from anywhere.
  • Memory integrity has to be off, and that removes a real layer of defence.
  • Small grey text sits in your desktop corner. Some games with anti-cheat won't start.
  • On a work PC this may be a bad deal. Only you can judge that.
  • A Microsoft-checked driver would remove all of it.
Show the technical details

The KMDF item snapshots the main branch of magic-mouse-v3-windows-fix and looks for v2-kmdf-driver/Install-KMDF.cmd. No copy is on that branch, so the install errors and never falls back.

Both routes need bcdedit /set testsigning on and HVCI off, and both undo. Patched Apple driver runs v1-binary-patch/installer/Install-MagicMousePatch.ps1, which is on the branch, with scroll and battery mutually exclusive.

Questions

Which driver does my Apple Magic Mouse need on Windows 10 or 11?
The Magic Mouse v1 (030D), the Magic Mouse v2 (0269) and the Apple Wireless Mouse (0310) all take Apple's own driver. The 2024 USB-C mouse (0323) has no finished scroll fix to download yet.
Can I make the 2024 USB-C Magic Mouse scroll on Windows yet?
Not yet. The community driver for that mouse isn't published, so nobody can download or install it, and its battery percent works with no driver anyway.
Will Magic Tray change my mouse driver without asking?
No, never on its own. Magic Tray opens a download page for the older Magic Mice, and for the 2024 mouse it asks before it installs anything.
My Magic Mouse still won't scroll. What do I check?
If the Driver tab still says Microsoft, run the install again. If nothing changed after a restart, unpair the mouse in Windows Bluetooth settings and pair it again.

Still no scrolling?

If an Apple Magic Mouse still won't scroll on Windows, check four things: an install that didn't take, a restart, a Windows update that swapped the driver back, and your device code.

  • The Driver tab still says Microsoft: the install didn't take, so do it again.
  • Nothing changed after a restart: unpair the mouse in Settings, then pair it again.
  • It worked, then stopped: a Windows update swapped the driver back. Install it again.
  • Windows shows 0323: there's no scroll driver to install yet. Read why.
  • Still nothing: open an issue about a Magic Mouse that won't scroll. Give your Windows version and mouse code.

Keyboards and trackpads

  • Magic Keyboard: no driver to swap. Its battery needs a one-time unlock.
