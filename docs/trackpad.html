Gestures: one third-party driver

MagicTrackpad2ForWindows is GPL-2.0 licensed and signed by Microsoft, so it needs no Test Mode and no Memory integrity off. It is not ours, we have not tested it, and we get nothing if you install it.

MagicTrackpad2ForWindows, in its own words
  • It is a Magic Trackpad 2 Precision Touchpad driver for Windows 11, based on the imbushuo driver, GPL-2.0 licensed and signed by Microsoft. Its author paid for the certificate himself, so it needs no Test Mode and no Memory integrity off.
  • Latest release: v2.0, 25 February 2026. One file, MT2FW11-20260223-MSSigned.zip, 316,588 bytes.
  • What it targets: Windows 11 and the Magic Trackpad 2. Its notes say Windows 10 on AMD64 needs a workaround from its issue tracker, and Windows 10 on ARM64 is unsupported.
  • What its README claims beyond that: USB-C Magic Trackpad 2 support, battery level reading, haptic feedback control. Its claims, not ours.
  • Follow its own instructions, not ours: it says to uninstall Magic Utilities and Trackpad++ first.

The AA-battery 030E has a submenu that opens Apple's own Boot Camp wireless trackpad download page and nothing else: Magic Tray installs nothing, you run the file. You don't need it for the battery percent. For 0265 and 0324 the app offers no driver change.

Common questions

Does a Magic Trackpad need a driver on Windows 10 or 11?

No. Pair it in Windows Bluetooth settings and the pointer moves and the surface clicks. Magic Tray reads the battery percent with nothing else installed. A driver comes into it only if you want gestures, and that driver is not ours.

Why are there no trackpad gestures on Windows?

Because Windows treats a Magic Trackpad as an ordinary mouse. It never shows a Touchpad page in Settings for it, so two-finger scrolling, pinch to zoom and three-finger swipes do nothing. Magic Tray does not change that: it reads batteries and adds no gestures.

Can I use a Magic Trackpad on a PC that is not a Mac?

Yes. Any Windows 10 or 11 PC with Bluetooth pairs one and uses it as a pointer. You don't need a Mac, and you install nothing called Boot Camp, which is only Apple's name for its own Windows drivers.

Has anyone confirmed the battery percent on a Magic Trackpad?

Not yet. Magic Tray knows all three trackpads and should read a percent from each, but no test report exists for any of them. The three devices that are confirmed were all tested by the author on his own PC, so no trackpad on this page has an independent report behind it. A report from you would fix that.
