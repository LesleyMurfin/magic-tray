Magic Trackpad on Windows 10 and 11

A Magic Trackpad moves the pointer and clicks on Windows 10 and 11 as soon as you pair it, and Magic Tray shows its battery percent for free. Windows gives you no gestures, and Magic Tray does not add any.

  • Nothing to install for the basics. Pointer, clicks and the battery percent all work on Windows as it came.
  • No scroll fix here. The scrolling driver on this site is for a Magic Mouse. A trackpad has no equivalent from us.
  • No trackpad has been confirmed. All three should work. Nobody has reported back yet.

Does the Magic Trackpad work on Windows 11?

Yes, as a pointer. Pair it in Windows Bluetooth settings and it moves the cursor and clicks when you press the surface, on Windows 11 and on Windows 10. Windows sees it as an ordinary mouse, which is the whole story: you get everything a mouse does, and nothing a touchpad does.

Does a Magic Trackpad need a driver for the battery percent?

No. Install Magic Tray, pair the trackpad, and the percent appears in the tray menu. There is no unlock to run, unlike a Magic Keyboard, and no driver to swap, unlike a Magic Mouse that will not scroll. Where to look for the number.

Magic Tray recognises all three and should read a percent from each. None of them is confirmed, so treat the table as "should work, nobody has confirmed it yet" rather than a promise.

One trackpad has a driver item in the menu: the AA-battery 030E. Its submenu can open Apple's own Boot Camp wireless trackpad download page, and that is all it does — Magic Tray installs nothing and you run the file yourself. You do not need it for the battery percent. For 0265 and 0324 the app offers no driver change at all and refuses to try.

Can I get Magic Trackpad gestures on Windows?

Not from Windows, and not from Magic Tray. Somebody else's driver does it, and it is free.

MagicTrackpad2ForWindows describes itself as a Magic Trackpad 2 Precision Touchpad driver for Windows 11, based on the imbushuo driver and signed by Microsoft. It is GPL-2.0 licensed, and its author writes that he paid for the certificate himself so that Windows would accept it. Being Microsoft-signed is the part that matters to you: it needs no Test Mode and no Memory integrity switched off, unlike the 2024 Magic Mouse route.

  • Latest release: v2.0, published 25 February 2026, on its releases page. One file, MT2FW11-20260223-MSSigned.zip, 316,588 bytes.
  • What it targets: Windows 11, and the Magic Trackpad 2. Its own notes say Windows 10 on AMD64 works only through a workaround posted in its issue tracker, and that Windows 10 on ARM64 is not supported.
  • What its README claims beyond that: support for the USB-C Magic Trackpad 2, battery level reading, and haptic feedback control. Those are its claims, not ours, and we have checked none of them.

It is not ours and we have not tested it. We are not connected to that project and we get nothing if you install it. Follow its own instructions rather than anything written here, because a driver's steps go stale the moment someone copies them: it tells you to remove older trackpad drivers first, and says it is especially important to uninstall Magic Utilities and Trackpad++ before you start. A driver changes how Windows sees your hardware, so read the page you are installing from.

If all you wanted was the number on the battery, you do not need any of this. Magic Tray shows it as it is.

Which Magic Trackpad do I have?

Look at the back edge. A round cap you unscrew means the AA-battery model; a charging port means one of the rechargeable ones. The four-character code Windows shows is the answer that never lies, and one page owns that check: the trackpad photographs and where to read the code in Device Manager.

Can you help test a Magic Trackpad?

No trackpad has ever been confirmed. Three devices are confirmed on this project, and all three were tested by the author on his own PC, so nothing on this page has an independent report behind it. A trackpad report is the single most useful thing you can send.

We need the battery percent only — there is no driver from us to test. Tell us:

  • Which trackpad you have
  • Its four-character device code (where to find that)
  • Your Windows version
  • Whether Magic Tray showed a percent, or No reading

Send a report. "It didn't work" is as useful as "it worked". Other devices need testers too.

Common questions

Does a Magic Trackpad need a driver on Windows 10 or 11?

No. Pair it in Windows Bluetooth settings and the pointer moves and the surface clicks straight away, on Windows 10 and Windows 11. Magic Tray reads the battery percent with nothing else installed either. A driver only comes into it if you want gestures, and that driver is not ours.

Why are there no trackpad gestures on Windows?

Because Windows treats a Magic Trackpad as an ordinary mouse. It never shows a Touchpad page in Settings for it, so two-finger scrolling, pinch to zoom and three-finger swipes do nothing. Magic Tray does not change that: it reads batteries and adds no gestures.

Can I use a Magic Trackpad on a PC that is not a Mac?

Yes. Any Windows 10 or Windows 11 PC with Bluetooth will pair a Magic Trackpad and use it as a pointer. You do not need a Mac, and you do not need to install anything called Boot Camp, which is only Apple's name for its own Windows drivers.

Has anyone confirmed the battery percent on a Magic Trackpad?

Not yet. Magic Tray knows all three trackpads and should read a percent from each, but no test report exists for any of them. The three devices that are confirmed were all tested by the author on his own PC, so no trackpad on this page has an independent report behind it. A report from you would fix that.
