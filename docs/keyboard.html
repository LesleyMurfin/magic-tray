Magic Keyboard battery on Windows 10 and 11

No new driver, no Apple software: one unlock turns the percent on.

The one-time unlock, in six steps

  1. 1
    Pair the keyboard in Windows Bluetooth settings.
  2. 2
    Click the Magic Tray icon beside the clock.
  3. 3
    Point at your keyboard's name to open its submenu.
  4. 4
    Click Fix battery reads.
  5. 5
    Click Yes when Windows asks for admin permission.
  6. 6
    Turn Bluetooth off and on again.
Where the percent shows, what changes, and how to help test

The percent then shows in the tray menu: where to look · low battery warnings

Windows keeps its own Bluetooth driver, nothing from Apple is installed, and no Test Mode is involved, unlike the 2024 mouse. Re-pairing the keyboard wipes the unlock, so run it again after you re-pair.

To run it yourself instead: grab Install-KeyboardBattery.cmd from the release page, right-click it and pick Run as administrator.

On col02 the keyboard declares Battery Strength at RID 0x47 as Input-only, so FeatureReportByteLength is 0 and HidD_GetFeature returns nothing. Measured: 6,859 consecutive read timeouts, and a 255-RID sweep with zero hits.

The patch relabels 0x47 as a Feature report in the BTHPORT CachedServices SDP cache, and re-pairing rebuilds that cache. Source: MagicMouseTray/KeyboardBatteryDevice.cs and scripts/kbd-patch-cachedservices.ps1.

Only the 2011 Apple Wireless Keyboard (0239) is confirmed. The rest of the family (024F, 0250, 0267, 026C, 029C) should work, but nobody has reported one yet. Send your keyboard, its four-character code, your Windows version, and whether the percent showed before and after: send a report.

Common questions

Why doesn't my Magic Keyboard battery percent show up?

Your keyboard sends its battery level, but labels it in a way Windows will not answer for, so the number never reaches the tray. The unlock relabels it once.

Does the unlock survive re-pairing the keyboard?

No. Re-pairing wipes it. Run Fix battery reads again from the Magic Tray menu. Until you do, Magic Tray lists your keyboard but shows the battery as blocked.
