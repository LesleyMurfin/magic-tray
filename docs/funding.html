Magic Tray · support

Help fund a Magic Mouse driver checked for Windows 10 and 11

Magic Tray and the driver are free. Nobody has paid for Microsoft's check on the driver.

What the money buys

Microsoft's check removes the security warning when you install the driver, and the Windows startup setting you must change to make the 2024 mouse scroll. Everyone gets that, not only donors.

No sponsor button yet: GitHub hasn't approved the page. Donations would pay for that check; nothing is held back if nobody donates.

Questions

Why does Windows warn me when I run Magic Tray?

Windows SmartScreen warns about newly published files it does not recognise. Check the release's published SHA-256 before you run it.
