What it actually does

Which driver

v3 → KMDF. v1/v2 → Boot Camp. Keyboard → SDP. Trackpad → battery only. Hardware Ids are the authority.

Why v3 ≠ v2

0323 is missing from Boot Camp. HID Mode A/B. Linked research in the kernel repo, not a guessed INF.

Stars & signing

Star both repos. Goal: EV cert + attestation so KMDF drops Test Mode. No scroll-killing trial.

Flip the device, then confirm the PID

The charging port (or AA door) is a hint. Device Manager Hardware Ids win. Full walkthrough: How to tell Magic device versions apart.
