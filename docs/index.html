What does Magic Tray do on Windows 10 and Windows 11?

Magic Tray is a free app that sits in the Windows system tray, next to the clock. It shows the battery percent of your Apple Magic Mouse, Magic Keyboard and Magic Trackpad, and warns you at 10, 5 and 1 percent. It also installs the Windows scroll driver that a Magic Mouse v1 (AA batteries) or v2 (Lightning) needs.

Is Magic Tray a physical desk tray or stand?

No. Magic Tray is software you download and run on a Windows PC. It lives in the system tray, the little row of icons beside the Windows clock. If you came here looking for a wooden or 3D-printed stand for an Apple keyboard, this is the wrong page.

Does Magic Tray run on Windows 10, or only Windows 11?

Both. You need 64-bit Windows 10 version 1809 or newer, or any Windows 11. There's no macOS version, because macOS already shows Apple battery levels. On the first run Windows may warn you that it doesn't know the app. Click More info, then Run anyway.

Is Magic Tray free, or does it need a subscription?

It's free, and the source code is public under the MIT license. There's no trial, no account and no monthly fee, so your scrolling can't stop working because a payment failed. If Magic Tray helped you, star the GitHub repo. That's the only thing we ask for.

Which Apple Magic mouse, keyboard and trackpad models work with Magic Tray?

Battery percent works for the Magic Mouse v1 (AA batteries), v2 (Lightning) and the 2024 model with the USB-C port. We call that newest one v3; Apple just calls it Magic Mouse (2024). Magic Keyboard and Magic Trackpad also show battery. The scrolling Windows driver is for the mouse only.

How do I tell which Magic Mouse I have: v1, v2 or the 2024 USB-C model?

Turn the mouse over and look at the bottom. A door with two AA batteries under it means Magic Mouse v1. A small Lightning socket means Magic Mouse v2. A wider USB-C socket means the 2024 model, which this project calls Magic Mouse v3. The connector is the giveaway.

Windows tells models apart by their PID, the four-character code inside a device's hardware id. To read yours, open Device Manager, right-click your mouse, then pick Properties, Details, Hardware Ids. You'll see something like PID_0323.

Two names come up in the cards below. Boot Camp is Apple's own pack of Windows drivers, and it covers Magic Mouse v1 and v2. KMDF is a Windows driver that runs deep inside the system, and that's the sort the 2024 USB-C mouse needs.

How do I download and run Magic Tray on Windows?

Download MagicMouseTray.exe from the GitHub releases page and double-click it. There's no installer, and it doesn't need admin rights. Battery percent appears as soon as a supported device is paired. Windows may show a SmartScreen warning first, because the app isn't signed yet.

Three steps to battery percent in the Windows tray

  1. Pair your Magic Mouse, Magic Keyboard or Magic Trackpad in Windows Bluetooth settings.
  2. Download MagicMouseTray.exe from Releases and run it.
  3. Click the tray icon. Each paired device shows its percent.

Want keyboard battery too? Run the keyboard patch from the same download. Magic Tray leaves your Windows drivers alone until you pick a driver yourself and approve the Windows permission prompt.

Why doesn't my Magic Mouse scroll on Windows 10 and Windows 11?

Windows has no built-in driver for the touch surface on top of a Magic Mouse, so the pointer moves but the wheel does nothing. On a Magic Mouse v1 (AA batteries) or v2 (Lightning), Apple's Boot Camp Windows driver fixes it. On the 2024 USB-C model, scrolling still needs an experimental driver.

Magic Mouse v1 and v2: install Apple's Boot Camp Windows driver

Boot Camp is Apple's own pack of Windows drivers, built for Macs that also boot Windows. Its mouse driver covers Magic Mouse v1 and v2. Apple signed it, so Windows loads it without any special settings. Magic Tray can install it for you, or you can install the INF yourself.

An INF is the small text file Windows reads to set a driver up. Right-click it, choose Install, and reboot if Windows asks you to. Full steps for Magic Mouse v1 and v2.

Magic Mouse v3 (2024, USB-C): battery works now, scrolling is still experimental

Battery percent works on this mouse with no driver at all. Scrolling doesn't, because Apple's Boot Camp pack has no entry for PID 0323. A separate project builds a KMDF driver for it. KMDF is the kind of Windows driver that runs deep inside the system, alongside Windows' own code.

Microsoft hasn't signed that driver, so Windows only loads it if you switch Test Mode on and turn Memory integrity off. Test Mode is the Windows setting that allows unchecked drivers. It puts a watermark on your desktop and lowers your security. Magic Tray can't install this driver yet.

Does Magic Tray replace Magic Utilities?

No. Magic Utilities is paid software with Microsoft-signed drivers and gestures, and it does more than Magic Tray does. Magic Tray is a free battery meter that can also set up Magic Mouse scrolling. We're not connected to Magic Utilities in any way. If you want gestures, buy theirs.
