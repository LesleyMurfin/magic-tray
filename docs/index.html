Free · Windows 10/11 · not Magic Utilities

Battery next to the clock. Scroll that actually works.

  • Magic Tray is a tiny program by the Windows clock.
  • It shows how much battery is left in your Apple mouse, keyboard, or trackpad.
  • If your Magic Mouse will not scroll, it can add the extra Windows piece that mouse needs.
  • Free. No monthly fee.

Which mouse?

  • Flip the mouse over.
  • Battery door, Lightning hole, or USB-C hole?
  • Then check Device Manager → Details → Hardware Ids. Windows uses a code like PID_0323.
