Magic Tray 1.1.0 · MIT · Windows 10/11

Magic Mouse battery and scroll on Windows. No subscription.

Magic Tray is a free tray app for Apple Magic Mouse (v1, v2, and Magic Mouse 2024 / Magic Mouse v3, PID 0323), Magic Keyboard, and Magic Trackpad. Battery percent in the tray. Scroll driver you confirm. Not Magic Utilities.

Download v1.1.0 Docs on GitHub

What it covers

Magic Mouse v1 / v2 / v3

Battery in the tray. v3 (2024 USB-C) uses KMDF for scroll and battery. v1/v2 use Boot Camp.

Magic Keyboard

Battery after a one-time SDP patch. You must pass the keyboard Bluetooth MAC. No kernel driver.

Magic Trackpad

Battery and alerts only. No tap-to-click, 3-finger, or MU trackpad gestures.

Not Magic Utilities

  • Free, MIT. No trial that disables scroll.
  • No MU binaries or WHQL MU drivers.
  • No desktop swipes, media-key remaps, or trackpad suite.

Install steps, Test Mode for Magic Mouse v3, and the driver matrix: README. v3 HID research: magic-mouse-v3-windows-fix.

FAQ

Does Magic Mouse 2024 (Magic Mouse v3) work on Windows 11?
Yes. Use Magic Tray 1.1.0 and install the KMDF driver from magic-mouse-v3-windows-fix. That path needs Test Mode and Memory Integrity off. Battery is HID Input 0x90 on COL02.
Is this Magic Utilities?
No. Free MIT. No subscription. No MU binaries. No gesture / trackpad / media-key suite.
Will scroll stop when a trial expires?
No. There is no trial.
Do trackpads get scroll or tap-to-click?
No. Battery and alerts only.
