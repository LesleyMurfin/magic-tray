What does Magic Tray do?

Magic Tray is a free Windows 10 and Windows 11 tray app. It shows the battery percent of your Apple Magic Mouse, Magic Keyboard and Magic Trackpad next to the clock, warns you at 10, 5 and 1 percent, and helps an Apple mouse scroll again after you confirm.

A driver is the software Windows uses to talk to your mouse. For older mice Magic Tray only opens the download page.

Which Magic Tray page do I want?

Pick by the problem. Battery percent missing on a mouse or trackpad, start with the battery page. Battery percent missing on a keyboard, you need the one-time unlock. Mouse moves but won't scroll, you need a driver. Not sure which Apple device you own, start with the identification page.

Install it in three steps

  1. Pair your device in Windows Bluetooth settings.
  2. Download MagicMouseTray.exe from GitHub and double-click it.
  3. Windows may warn you. Click More info, then Run anyway.

Is Magic Tray free?

Magic Tray costs nothing and always will. It is MIT licensed, every line is public on GitHub, and there is no subscription, no trial, no account and no email address to hand over. Scrolling will not stop working if nobody ever donates a penny.

Questions

Is Magic Tray a desk stand?
No. Magic Tray is downloadable Windows software that sits beside your Windows 10 or 11 clock. It is not a desk tray, riser or cradle for an Apple keyboard.
Does Magic Tray work on Windows 10?
Yes. Magic Tray runs on 64-bit Windows 10 version 1809 or newer, and on any Windows 11.
Does an Apple Magic Mouse work with Windows 11?
Yes. Pair it in Windows Bluetooth settings and it clicks and moves straight away, on Windows 11 and Windows 10. Scrolling with one finger is the part Windows doesn't do, and that needs a driver. Magic Tray adds the battery percent Windows never shows.
Do I need a Mac to use an Apple mouse or keyboard on Windows?
No. Magic Tray is a Windows PC app and everything here runs on Windows 10 or Windows 11 alone. Apple's old mouse drivers are called Boot Camp, which is a Mac name, but you download and install them on Windows without owning a Mac.
Is Magic Tray safe to install?
Magic Tray is MIT licensed and every line is public on GitHub, so you can read what it does. Windows warns you on first run because nobody has paid for Microsoft's check, which costs money. Magic Tray changes no driver until you pick one and confirm.
Will Magic Tray change my drivers on its own?
No. Magic Tray only touches a driver after you pick it from the tray menu and confirm.
